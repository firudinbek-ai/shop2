# Новый Магазин

Приложение для учёта выручки магазина.

## Возможности

- Ввод продаж по трём типам: НАЛ, ТЕР, ПЕР
- Автоматический подсчёт выручки
- Учёт выхода (2000 ₽)
- Учёт других расходов
- Возврат наличными
- Автоматический расчёт кассы
- Работает офлайн
- Устанавливается как приложение на Android
